## Run Locally

Install the .NET 9 SDK and run:

```powershell
dotnet restore CSE325GroupProject/CSE325GroupProject.csproj
dotnet run --project CSE325GroupProject/CSE325GroupProject.csproj
```

Open the local URL displayed in the terminal.
